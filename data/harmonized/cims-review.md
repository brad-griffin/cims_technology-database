# CIMS technology review

Generated by `data/harmonized/build-cims-review.py` from `cims-map.csv`, which is
itself generated by `build-cims-map.py` from the CIMS model inputs in
`data_processing_calibration/cims/data/model_inputs/model/`. Re-run both after
changing the mapping rules — nothing here is hand-maintained.

## 1. What the mapping found

| Outcome | Rows | What it means |
| - | - | - |
| `retain` | 636 | maps cleanly onto one harmonized technology; keep the technology, rename it |
| `merge` | 95 | same device as another row at the same service node, differing only in efficiency wording — the `efficiency-*` variant already carries that |
| `merge-review` | 491 | collapses onto another row, but CIMS draws a sub-type distinction the harmonized name does not — **needs a decision** |
| `fuel-node` | 205 | CIMS models a fuel choice as a technology; there is no device to name |
| `review` | 142 | no equipment or carrier keyword matched — **needs a human** |
| `out-of-scope` | 709 | residential, commercial, transport or electricity supply; outside this database's industrial scope |

1569 industrial CIMS technologies reduce to 187 distinct harmonized names.

### Unprefixed twins

its siblings once the model is read by anyone but its author.

the harmonized name has no slot for the sub-type CIMS names. Either add variant terms
to section 6.2 of the design document, or accept the merge and lose the distinction.

The motor, pump, fan, compressor and conveyor families are the bulk of this. They are
also where CIMS carries size classes (`Size 1`…`Size 6`, `Small`/`Large`) as separate
service nodes, which the harmonized layer preserves as `process-step` — so size is not
at risk here, only sub-type.

## 5. Structural: fuel choices modelled as technologies

197 CIMS technologies are a bare fuel name — `NG`, `Electric`, `H2`,
`Renewable Natural Gas`, `Heavy Fuel Oil`, `Thermal Coal`. There is no device to name.
In the harmonized layer these are `tech-flow` input rows on the parent technology, not
technologies. Keeping them as technologies in CIMS is a modelling choice, not an error —
